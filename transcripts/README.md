# Session transcripts

Readable exports of the AI sessions behind the prompt journal (`docs/PROMPT_JOURNAL.md`). They back up the journal entries with the full conversation.

Each export contains the user's messages, the AI's replies, one-line notes for each tool call, and any subagent reports. It leaves out the AI's internal reasoning, raw tool output and system metadata.

**Before committing an export:** check it for secrets, tokens and personal data. The repo may be public.
